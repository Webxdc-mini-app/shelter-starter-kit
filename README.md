# 避難所運営スターターキット

地図・入退場・物資・安否・当番の5つのアプリをひとつにまとめ、チャットで避難所運営を支えるスターターキットです。

**対象バージョン：1.2.3**  
配布ファイル：`shelter-starter-kit-1.2.3.xdc`  
確認日：2026年10月28日

## 操作マニュアル

はじめて使う方は、画面図入りの操作マニュアルをご覧ください。HTML版は画面図を押すと拡大できます。PDF版はA4・15ページです。Word版は文章を編集して配布用の手順書にできます。

- [HTML版の操作マニュアル](shelter-starter-kit.html)

## 最初の設定

1. 運用するDelta Chatのグループチャットへ、XDCファイルを添付します。
2. 全員が、案内された**同じチャットの同じ添付**を開きます。別の添付として送り直すと、別の台帳になります。
3. ホーム上部の「管理者設定」を1回押します。初期パスワードは **`secret`** です。
4. 担当名を入れ、必要なアプリへチェックを付けます。初期状態では5アプリすべて非表示です。
5. 運用前にパスワードを変更し、「保存して閉じる」を押します。
6. 各端末で同じ手順の表示設定を行います。設定とパスワードは他端末へ共有されません。

「管理者設定」を開くタップ数は1〜20回に変更できます。複数回の場合は前のタップから4秒以内に続けて押します。新しいパスワード欄を両方空にすると、現在のパスワードを維持します。忘れたパスワードを復旧する機能はありません。

## 5つのアプリでできること

| アプリ | 主な使い方 |
|---|---|
| ちゃっとピンマップ | 地図画像の上に場所・設備・危険箇所のピンやルートを登録 |
| ちゃっと入退場 | 人物QRの発行、入所・一時外出・帰所・正式退所の記録 |
| ちゃっと物資管理 | 物資の登録、棚卸し、入庫、配布・使用、不足の確認 |
| ちゃっと安否確認 | 人物の安否・滞在状況・必要な支援・引継ぎの記録 |
| ちゃっと当番表 | 当番の作成、本人に確認した参加予定・実績・引継ぎの記録 |

ホームから担当アプリの大きなボタンを押して開きます。入力後は各画面の保存・記録ボタンを押し、上部の「← ホームへ」で戻って集計を確認します。戻る操作だけでは入力内容を確定しません。

アプリ内部に管理者設定がある場合は、ホームの管理者設定とは別です。ホームのパスワードを変更しても、同梱アプリ内部のパスワードや権限は変更されません。

## ホームの数字

「このキットの自動集計」では、キット内で入力した記録を表示します。

| 表示 | 意味 |
|---|---|
| 在所人数 | 現在、記録上で在所している人。一時外出を含まない |
| 受入継続人数 | 在所人数＋一時外出中の人数 |
| 不足物資 | 不足・少ない、または不足目安以下の物資の品目数 |
| 安否未確認 | 安否が未確認・連絡取れず等の対象件数 |
| 今日の当番 | 本日を開始日にした、閉じていない当番の件数。担当人数ではない |

例：在所5人・一時外出3人なら「在所人数5人」「受入継続人数8人」です。「—」は未読込などで表示できない状態で、0人・0件とは異なります。

## 端末間の共有とアプリ間の連携

- 記録は、通信後に同じXDC添付を開いている端末へ共有されます。通信できない間に端末へ保存した記録は、送信待ちや未受付の表示を確認してください。
- 「送信待ちなし」は、全員が受信・確認したことを保証しません。交代時は別端末の記録も確認します。
- ホームの「共有を再送」は、ホームへ取り込んだJSON参照情報の送信待ちを再送します。各アプリ内の送信待ちは、そのアプリも開いて確認してください。
- 入退場の人物情報は、安否名簿と当番候補へ連携します。手入力した項目を優先し、安否を自動で「無事」にしたり、当番の参加を自動で決めたりはしません。
- 入退場で物資受取を記録しても、物資管理の在庫は自動で減りません。地図への自動登録も行いません。
- 別添付・別チャット・別の単体アプリとは、自動で記録が合流する仕組みではありません。

## 単体アプリのJSONを取り込む

1. 元アプリで対応するJSONを書き出します。CSVは対象外です。
2. ホームの「JSONを取り込む」を押します。
3. 「元台帳ID」を入力し、JSONファイルを選びます。同じ台帳を更新する場合は、毎回同じIDを使います。
4. 「2. 内容を確認する」を押し、元アプリ・会場・書出日時・表示対象・警告を確認します。
5. 参加者へ共有する内容を確認してチェックを付け、「この内容で取り込む」を押します。
6. ホームの「外部JSON参照」に切り替えて、取り込んだ時点の情報を確認します。

元台帳IDは64文字まで、入力ファイルは10MB・履歴2万件までです。取り込み後の共有情報にも容量制限があります。

**外部JSONは参照表示です。** 同じ元台帳・会場のデータは置き換え、人数や在庫へ加算しません。キット内の自動集計とも合算しません。元アプリと自動同期せず、元アプリへ書き戻すこともありません。更新が必要なら、新しいJSONを同じ元台帳IDで取り込み直してください。

## PCでQRカメラが使えない場合

**Delta Chat PC版2.65.0では、Webxdcのカメラ権限が本体側で許可されていません。** `NotAllowedError: Permission denied` が出る場合、XDCの設定やWindowsのカメラ許可だけでは、この本体制限を解除できません。

入退場のQR画面で「保存済みのQR画像を選んで読む」を使ってください。1.2.3では画像選択欄を上部へ移し、カメラ起動失敗時の黒いプレビューを隠しています。手動貼り付けも利用できます。写真撮影の欄は、PCではファイル選択になる場合があります。

QRは人物IDを示します。人物の登録情報が同じ台帳に受信済みである必要があります。別の単体アプリで発行したQRだけを、未登録の統合台帳へ読ませても人物情報は移行されません。

確認元：[Delta Chat Desktop v2.65.0 公式ソース](https://github.com/deltachat/deltachat-desktop/blob/v2.65.0/packages/target-electron/src/deltachat/webxdc.ts)

## 表示言語

日本語・英語・中国語（簡体字）・韓国語・ベトナム語・タガログ語・フィリピン語・ポルトガル語・ネパール語・スペイン語・フランス語・ドイツ語・アラビア語・インドネシア語・ロシア語の15言語に対応します。

ホームの言語選択を各アプリへ引き継ぎます。氏名・物資名・住所・メモ等の入力内容は翻訳しません。翻訳文は、実際の運用前に利用者と確認してください。

## 表示を隠すことと情報の保護

管理者設定は端末ごとの**表示制御**です。メニューを隠しても、チャット参加者へ配信された記録を秘匿・削除する機能ではありません。安否や当番の画面で使う連携名簿も、そのアプリの表示対象に含まれます。

必要な人だけで情報を扱う場合は、参加者を限定した別チャット・別添付を使います。氏名・連絡先・医療情報等を入力・書き出し・JSON共有する前に、共有先と必要な範囲を確認してください。

## 版の変更と保管

新しいXDCを別添付で送ると別の台帳になります。既存の記録・端末設定は自動移行しません。運用中の添付を残し、必要な記録を書き出してから移行方法を確認してください。ホームへのJSON取り込みは、編集台帳を丸ごと復元する機能ではありません。

各アプリのJSON・CSVの用途と復元可否は異なります。すべてのJSONが完全復元用になるわけではありません。

## ブラウザで試す

`index.html`は1ファイルで開けます。追加ファイルを同じフォルダへ置く必要はありません。記録はそのブラウザ内に保存され、Delta Chat内の台帳・他の端末とは自動同期しません。ブラウザデータの削除や別ブラウザへの変更で、同じ記録を参照できなくなる場合があります。

## 問題が起きたら

同じチャット・同じ添付を開いているか、ホームの表示設定、通信状況、各アプリの送信待ちを確認します。起動エラーが表示された場合は「詳細（起動診断）」を開き、モジュール名とエラーを運用担当者へ伝えてください。診断情報は自動では外部送信しません。

操作マニュアルの「困ったときの確認」も参照してください。アプリの版・Delta Chat本体の版・端末の種類・操作順を控えると調査しやすくなります。
